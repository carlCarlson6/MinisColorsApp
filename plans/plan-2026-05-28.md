# Minis Colors App - MVP Implementation Plan

**Date:** May 28, 2026
**Scope:** Minimum Viable Product - Search closest paint color across brands

## 1. Overview

Build a web app where users select a color using a color picker, and the app searches the `colores.csv` database to find the most similar paint color per brand using perceptual color distance (CIEDE2000 Delta E).

## 3. Data Strategy

### 3.1 CSV Parsing
- **Parse at server startup**: Load `colores.csv` once when the server starts. No database needed for the MVP.
- **Library**: `papaparse` (handles quoted newlines like the one in row 80-81).

### 3.2 Data Cleaning
- **Skip invalid rows**: Any row with a hex in scientific notation (`7.05E+50`, `3.84E+51`, `2.73E+53`) or malformed hex (like `849B63|`) will be filtered out.
- **Skip empty cells**: Any empty cell in a brand column is ignored.

### 3.3 Data Flattening
- Each non-empty cell in the 12 brand columns becomes an individual paint record:
  ```typescript
  {
    brand: string;        // e.g., "NewCitadel"
    name: string;         // e.g., "Abaddon Black"
    hex: string;          // e.g., "000000"
    lab: [number, number, number]; // Pre-computed Lab values
  }
  ```

### 3.4 Notable Data Edge Cases Handled
- **Row 80-81**: `INSTARVintage` column contains a quoted newline (`"IV-11\nIV-12 7"`). PapaParse will handle this.
- **Row 64**: Hex `849B63|` → malformed, row skipped.
- **First column empty**: Rows 100–112 have empty `NewCitadel` but still contain valid paints in other columns. These will be included under their respective brands.

## 4. Matching Algorithm (Server Function)

### 4.1 Input
User-selected hex color (e.g., `#FF0000`).

### 4.2 Process
1. Convert input hex to Lab color space using `culori`.
2. Compute CIEDE2000 Delta E distance between input and every valid paint record.
3. Group results by brand.
4. Pick the single closest match (lowest Delta E) per brand.
5. Sort the final results by Delta E (ascending).

### 4.3 Output
Sorted array of matches:
```typescript
{
  brand: string;
  name: string;
  hex: string;
  deltaE: number;
}
```

## 5. UI Plan

### 5.1 Single Page (`/`)
- **Header**: App title "Minis Colors" + brief description.
- **Color Picker Section**:
  - Large `react-colorful` color picker.
  - Hex input field for manual entry.
  - "Find Matches" button.
- **Results Section** (shown after search):
  - Responsive grid or list of closest matches.
  - Each card shows:
    - Brand name
    - Paint name
    - Color swatch (div with background color)
    - Delta E value (rounded to 2 decimals)
- **Empty State**: Show instructions when no search has been performed.
- **No Results State**: Show message if input color has no valid matches (edge case).

### 5.2 Design Notes
- Clean, responsive layout.
- High contrast for accessibility.
- Color swatches should be large enough to be visually useful.
